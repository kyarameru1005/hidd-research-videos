# HIDD 先行研究 紹介動画 統合サイト

先行研究の紹介動画を 4 カテゴリに分けて閲覧できる静的サイトです。
トップページ中央の球体を回してカテゴリを選び、カテゴリページから Google ドライブ上の動画を再生します。

## 開き方

ビルド工程はありません。次のどちらでも動きます。

1. **そのまま開く** — `index.html` をダブルクリック（`file://` で開く）
2. **ローカルサーバーで開く**（推奨）

   ```sh
   cd /path/to/HIDD
   python3 serve.py
   # ブラウザで http://localhost:8000/ を開く
   ```

   > 標準の `python3 -m http.server` は **Range リクエスト（部分取得）に対応していません**。
   > 動画のシークができず、再生位置の復元も効かないため、動画を扱う場合は必ず
   > 同梱の `serve.py` を使ってください。

Google ドライブの動画を再生するにはインターネット接続が必要です。
Three.js は `vendor/` に同梱しているため、球体の表示自体はオフラインでも動きます。

## 動画データの入れ方

編集するのは **`js/data.js` の 1 ファイルだけ**です。各カテゴリの `videos` 配列を書き換えます。

```js
{
  title: 'AR を用いた展示ガイドの制作',   // 動画のタイトル
  presenter: '〇〇研究室',                // 発表者・研究室名（省略可）
  summary: '一行程度の概要。',            // 概要（省略可）
  driveId: '1AbCdEfGhIjKlMnOpQrStUvWxYz', // Google ドライブのファイル ID
}
```

### `driveId` の調べ方

ドライブで動画を右クリック →「リンクをコピー」で得られる URL の、`/d/` と `/view` に挟まれた部分です。

```
https://drive.google.com/file/d/1AbCdEfGhIjKlMnOpQrStUvWxYz/view?usp=sharing
                                ^^^^^^^^^^^^^^^^^^^^^^^^^^^^ ここが driveId
```

`driveId` の代わりに `url: 'https://...'` と直接書くこともできます（YouTube などドライブ以外を混ぜたい場合）。

### 共有設定（重要）

各動画の共有設定を **「リンクを知っている全員」／閲覧者** にしてください。
限定公開のままだと、サイト内の埋め込みプレーヤーで再生できません。
再生できない場合に備えて、モーダル下部に「Google ドライブで開く」リンクを併記しています。

### カテゴリを変えたい場合

同じく `js/data.js` の `categories` を編集します。1 カテゴリは次の項目を持ちます。

| キー | 用途 |
|---|---|
| `id` | URL に使う識別子（`category.html?cat=<id>`） |
| `label` | カテゴリ名。球体・一覧・見出しすべてで使う |
| `accent` | そのカテゴリのアクセントカラー |
| `description` | カテゴリページの説明文 |

**球体上の配置は自動です。** 配列に足す／減らすだけで並び直ります（記載順＝並び順）。
5 個までは「上・右・下・左・後ろ」の軸方向へ順に割り当て、6 個以上になった場合は
正面を空けたまま真上から等間隔のリングへ自動で切り替わります。
正面は HIDD の表示用に常に空きます。配置の指定項目はありません。

現在は 5 カテゴリなので、上下左右と後ろに 1 つずつ並びます。

| # | カテゴリ | 球体上の位置 | 色 |
|---|---|---|---|
| 1 | AI・機械学習・知能システム | 上 | 青 `#5ac8fa` |
| 2 | ゲーム・VR・デジタルコンテンツ | 右 | 桃 `#ff7ac6` |
| 3 | Webサービス・アプリケーション開発 | 下 | 緑 `#7affa8` |
| 4 | サイバーセキュリティ・ネットワーク | 左 | 橙 `#ffc861` |
| 5 | IoT・ロボティクス・組込みシステム | **後ろ** | 紫 `#b58cff` |

5 番目は球体の裏側にあるため、既定の向きでは見えません。球体を回すと正面に出てきます
（画面下部の一覧からはいつでも選べます）。並び順を変えたい場合は `categories` 配列の順番を入れ替えてください。

## 球体の見た目を変える

現在は **「カテゴリ色の 4 分割グロー」** を使っています。上下左右をそれぞれのアクセント色でなめらかに染めた無地で、回すと正面のカテゴリ色に変わります。

テクスチャは画像ファイルではなく `js/texture-lab.js` が起動時に JavaScript で 1 枚だけ生成します。そのため `file://` で開いても動き、ダウンロードするファイルも増えません。

用意してある 6 案は `texture-demo.html` を開くと並べて見比べられます。別の案に変えたい場合は `js/sphere.js` の次の 1 行を書き換えます。

```js
var sphereMat = HIDDTexture.materials.quad();
//                                    ^^^^ ここを差し替える
```

| 指定 | 見た目 |
|---|---|
| `quad` | カテゴリ色の 4 分割グロー（現在の設定） |
| `dots` | 点描グリッド + カテゴリ色 |
| `circuit` | サーキット / 基板パターン |
| `rim` | 無地 + リムライト（最軽量） |
| `nebula` | 星雲 / ガス惑星風 |
| `globe` | 地球儀風（※ノイズで作った架空の大陸。実在の地図ではありません） |

## 操作方法

| 操作 | 動き |
|---|---|
| 球体をドラッグ | 回転（離すと慣性で少し流れる） |
| カテゴリをクリック | 正面に寄せてからカテゴリページへ移動 |
| 矢印キー | 球体を回転（球体にフォーカスがあるとき） |
| Tab / Enter | 画面下部のカテゴリ一覧から選択 |
| Esc | 動画モーダルを閉じる |

### 文字が見える条件

カテゴリ名と HIDD の文字は、**その面を正面に向けたときだけ**表示されます。
正面から約 21 度以内で全開、約 57 度で消えます。見えていないラベルはクリックもできません
（見た目と当たり判定を一致させるため）。既定の向きでは HIDD だけが見えます。

カテゴリの位置は球面上の色付きの点で分かります。画面下部の一覧からはいつでも選べます。

### 無操作時の自動回転

**1 分間まったく操作がないと、球体がゆっくり回り始めます。**
正面（HIDD）→ 上 → 右 → 下 → 左 → 後ろ → 正面… の順に巡回し、1 周およそ 30 秒です。
各カテゴリが正面に来るたびに、その名前が浮かび上がります。

- ドラッグ・キー操作・クリックのいずれかがあると即座に止まり、無操作時間の計測をやり直します
- タブが見えていないあいだは回りません（無駄な描画をしないため）
- OS の「視差効果を減らす」設定が有効な場合は回りません

待ち時間や速度は `js/sphere.js` の `IDLE_MS` と `TOUR_RAD_PER_SEC` で変えられます。

## 動作環境と設計上の配慮

高スペックでない PC で動かす前提のため、次のようにしています。

- **静止したら描画ループを止める** — 回転中・アニメーション中だけ `requestAnimationFrame` を回します（無操作時の自動回転が始まるまでは完全に停止しています）
- タブが非表示のあいだは描画しません
- 解像度は `devicePixelRatio` 1.5 までに制限
- ライトオブジェクトもポストプロセスも使わず、陰影とリムライトは 1 パスの軽いシェーダで処理
- テクスチャは起動時に 1 枚（512×256）生成するだけで、以降は再生成しません
- カテゴリ名は 3D テキストではなく HTML 要素を 3D 座標に追従させる方式（日本語が鮮明で、描画も軽い）
- WebGL が使えない環境では球体を出さず、カテゴリ一覧に自動で切り替わります
- OS の「視差効果を減らす」設定（`prefers-reduced-motion`）を有効にしている場合、アニメーションを行いません

## 星 + 放置時の自動再生（検討中）

`sphere-stars-demo.html` は、次の構想を実際に動かして確認するための検討用ページです。
**本番サイトには未適用です。**

- **1 等星 = カテゴリ**（光条つきの明るい星）。**その周りの小さな星 = 動画 1 本ずつ**
- 1 等星から各動画の星へ線を引いて星座にする
- 1 等星を押すとそのカテゴリを選択（正面へ回り、動画のタイトルが外向きに開く）。もう一度押すと解除
- 動画の星を押すと、その星からカードが生えて再生される
- 一定時間操作がないと球体が回り出し、さらに一定時間後にランダムな星を選んで自動再生する
- 再生が終わったら次の動画へ。どこかを触れば即座に止まる

ページ上部で待ち時間・星座線・またたき・音を切り替えて比較できます。

### 再生方式は 2 通りを自動で使い分けます

| `js/data.js` の指定 | 再生方式 | 自動再生 | 終了検知 | 再生位置の復元 |
|---|---|---|---|---|
| `file: 'videos/xxx.mp4'` | `<video>` | ○ | ○ | ○ |
| `driveId` のみ | ドライブの iframe | × | × | × |

Google ドライブの埋め込みは**別オリジンの iframe なので JavaScript から操作できません**。
無人での自動再生・連続再生をするには、動画ファイルをローカルに置く（または YouTube 限定公開に
移す）必要があります。`file` を書いたものから順に自動再生の対象になります。

### 動画ファイルの置き方

PowerPoint のビデオ出力（MP4 / H.264 + AAC）はそのまま使えます。先頭配置だけ直しておくと
再生開始が速くなります。

```sh
ffmpeg -i 発表.mp4 -c copy -movflags +faststart videos/ai-01.mp4
```

`videos/` は `.gitignore` に入れてあります（GitHub は 1 ファイル 100MB が上限のため）。
実物は USB や共有ドライブで配布し、展示機の `videos/` に置いてください。
`videos/sample/` だけは動作確認用に Git に含めています。

### 無人展示での安全装置

1 本読み込めなかっただけで画面が止まらないよう、**12 秒間再生が進まなければ自動で次の動画へ送ります**。
`<video>` のエラー時も同様です。ドライブ埋め込みの場合は終了を検知できないため 20 秒で送ります。
