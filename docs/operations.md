# 動かし方と展示運用

## 開き方

ビルド工程はありません。

### ローカルサーバーで開く（推奨）

```sh
cd /path/to/HIDD
python3 serve.py
```

- 本番サイト: <http://localhost:8000/src/>
- 検討用デモ: <http://localhost:8000/demo/>

> **`python3 -m http.server` は使わないでください。**
> Range リクエスト（部分取得）に対応しておらず、動画のシークと再生位置の復元が効きません。
> 同梱の `serve.py` はそこだけを補ったものです。

`serve.py` は配信のたびに `src/videos/<カテゴリid>/` を走査して動画一覧
（`src/js/videos.js`）を作り直します。**動画をフォルダに入れてブラウザを再読み込みすれば、
そのまま球体に反映されます。** サーバーの再起動は要りません。

### そのまま開く

`src/index.html` をダブルクリック（`file://` で開く）。
球体もカテゴリページも動きますが、次の点に注意してください。

- **ローカル動画のシークが不安定**になる可能性があります
- 動画一覧は **`serve.py` が最後に書き出した内容**が使われます。
  フォルダに足した動画を `file://` で見たいときは、一度 `serve.py` を起動して
  ブラウザで開き直してから（＝一覧を作り直してから）にしてください

## 動画ファイルの用意

### PowerPoint のビデオ出力ならほぼ変換不要

PowerPoint の書き出しは MP4（H.264 + AAC）なので、ブラウザがそのまま再生できます。
先頭配置だけ直しておくと再生開始が速くなります（**再エンコードしないので画質は劣化しません**）。

```sh
ffmpeg -i 発表.mp4 -c copy -movflags +faststart "src/videos/ai/研究テーマ（山田）.mp4"
```

**ファイル → エクスポート → ビデオの作成** では **フル HD (1080p)** を選んでください。
Ultra HD (4K) はファイルが無駄に大きく、展示 PC の負荷も上がります。

古い PowerPoint の `.wmv` はブラウザで再生できないので変換が必要です。

```sh
ffmpeg -i 発表.wmv -c:v libx264 -preset slow -crf 22 -pix_fmt yuv420p \
  -c:a aac -b:a 128k -movflags +faststart "src/videos/ai/研究テーマ（山田）.mp4"
```

### ブラウザが求める形式

| 項目 | 必要な形式 | よくある NG |
|---|---|---|
| コンテナ | MP4 | .mov / .avi / .wmv / .mkv |
| 映像 | H.264（AVC） | HEVC（H.265）、ProRes |
| 音声 | AAC | PCM、AC-3 |
| ピクセル形式 | yuv420p | yuv422p / yuv444p |

`-pix_fmt yuv420p` は必須です。これが無いと一部の動画が Chrome で真っ黒になります。

### 変換が要るかの確認

動画ファイルを Chrome にドラッグ＆ドロップして、再生とシークができれば変換不要です。

### 置き場所とファイル名

カテゴリごとのフォルダ（`src/videos/ai/` など）に入れます。**ファイル名がそのまま
タイトルと発表者になります**（`研究テーマ（山田）.mp4` → タイトル「研究テーマ」／発表者「山田」）。
配布された動画はたいていこの形なので、リネームせずそのまま置けます。
詳しい規則は [data.md](data.md) を参照してください。

## 展示（無人ディスプレイ）での運用

### トップページがそのまま展示モードになる

`src/index.html` を開いて放置するだけです。

1. **5 秒**操作がないと球体が回り出す
2. さらに **5 秒**後にランダムな動画を再生する
3. 最後まで再生したら次の動画へ進む（全部流すまで同じものは選ばれない）

秒数や 1 本あたりの再生時間は、下の「設定画面」で変えられます。

どこかを触れば止まり、そこからまた 5 秒で測り直します。

### 音を出すには開始時に 1 回だけ触れる

音は最初から出そうとしますが、ブラウザは**操作なしの音あり自動再生を止めます**。
止められた場合はミュートで再生を続けるので、映像は流れたままになります。

**展示を始めるときに画面へ 1 回だけ触れてください。** クリック・タップ・キー操作の
どれか 1 回で解除され、そのあとはページを開き直すまでミュートに戻りません。
これはこのサイト固有の仕組みではなく、ブラウザ側の仕様
（一度でも操作があったタブでは、以降の音つき自動再生を許可する）を利用しています。
1 回も触れないまま放置した場合は、最初の動画からずっとミュートのままになります。

**電源を入れたら誰も触らずに音を出したい**場合は、ブラウザ側の自動再生ポリシー
自体を無効にする必要があります。展示専用機であれば、その PC 専用のショートカットから
Chrome を次のオプション付きで起動してください。

```sh
# macOS の例。展示専用の空プロファイルで起動する
open -na "Google Chrome" --args \
  --autoplay-policy=no-user-gesture-required \
  --user-data-dir="$HOME/hidd-kiosk-profile" \
  "http://localhost:8000/src/"
```

このフラグはそのブラウザ起動全体に効くので、普段使いの Chrome とは
プロファイルを分けておくと安全です（`--user-data-dir`）。

### 自動再生の対象

`src/videos/<カテゴリid>/` に置いた動画がそのまま対象です。
まだ動画を入れていないカテゴリは確認用のサンプルが流れます。

### 安全装置

**12 秒間再生が進まなければ自動で次の動画へ送ります。** 1 本読み込めなかっただけで
画面が止まるのを防ぐためです。`<video>` のエラー時、および `file` 未配置のカードも同様です。

### 設定画面（Ctrl + Shift + S）

トップページかカテゴリページで **Ctrl + Shift + S** を押すと、右上に設定画面が開きます
（Mac でも Ctrl です）。展示の見た目を崩さないよう、画面には開くボタンを出していません。
もう一度同じキー、Esc、× のどれかで閉じます。上のタブで分類を切り替えます（左右キーでも移れます）。

| 分類 | 項目 | 選択肢 | 既定 |
|---|---|---|---|
| 自動再生 | 放置したときの自動再生 | する／しない | する |
| | 放置してから球体が回り出すまで | 5／10／30 秒 | 5 秒 |
| | 回り出してから動画を再生するまで | 3／5／10 秒 | 5 秒 |
| | 1 本あたりの再生時間（自動再生のときだけ） | 最後まで／30 秒／1 分／3 分 | 最後まで |
| 音 | 動画の音（どのページの動画も） | あり／なし | あり |
| | 音量 | 30／60／100% | 100% |
| 球体 | 慣性 | 弱い／ふつう／強い | 強い |
| | 大きさ | 小さめ／ふつう／大きめ | ふつう |
| | 星座線 | あり／なし | あり |
| | 星のまたたき | あり／なし | あり |
| | 画面下の操作ヒント | 表示／隠す | 表示 |
| カード一覧 | カードの流れる速さ | 止める／遅い／ふつう／速い | ふつう |
| リセット | 動画の続きの位置を消す | ボタン | — |
| | すべての設定を既定に戻す | ボタン | — |

- キーを押しても開かないときは、**ページを一度クリックしてから**押してください
  （アドレスバーなどにフォーカスがあると、キーがページに届きません）
- 選んだ値はその場で効き、**このブラウザに保存されます**（開き直してもそのまま）
- 展示を始めるときに全部の動画を頭から流したい場合は、「リセット」タブの「消して、最初から流す」を押してください
- **保存先は開き方ごとに別です。** `http://localhost:8000/src/` で設定した値は、
  `src/index.html` を直接開いたとき（`file://`）には効きません。
  展示専用のプロファイル（`--user-data-dir`）で起動している場合も、そのプロファイルの中で設定してください
- 開いている間は自動再生が止まります。60 秒触らなければ自動で閉じ、展示に戻ります
- 「動画の音: なし」にすると、上の「音を出すには」の操作をしても無音のままです

### 注意点

- ナレーションの無い PowerPoint 動画は音声トラック自体が無いので、
  上の「音を出すには」の話は関係ありません（もともと無音です）
- タブが見えていないあいだは球体の回転も自動再生も止まります（無駄な描画をしないため）。
  展示機ではブラウザを前面に出したままにしてください
- OS の「視差効果を減らす」設定が有効だと自動回転しません
