# 動かし方と展示運用

## 開き方

ビルド工程はありません。

### そのまま開く

`src/index.html` をダブルクリック（`file://` で開く）。
球体もカテゴリページも動きますが、**ローカル動画のシークが不安定**になる可能性があります。

### ローカルサーバーで開く（推奨）

```sh
cd /path/to/HIDD
python3 serve.py
```

- 本番サイト: <http://localhost:8000/src/>
- 検討用デモ: <http://localhost:8000/demo/>

> **`python3 -m http.server` は使わないでください。**
> Range リクエスト（部分取得）に対応しておらず、動画のシークと再生位置の復元が効きません。
> 同梱の `serve.py` はそこだけを補ったものです。

## 動画ファイルの用意

### PowerPoint のビデオ出力ならほぼ変換不要

PowerPoint の書き出しは MP4（H.264 + AAC）なので、ブラウザがそのまま再生できます。
先頭配置だけ直しておくと再生開始が速くなります（**再エンコードしないので画質は劣化しません**）。

```sh
ffmpeg -i 発表.mp4 -c copy -movflags +faststart src/videos/ai-01.mp4
```

**ファイル → エクスポート → ビデオの作成** では **フル HD (1080p)** を選んでください。
Ultra HD (4K) はファイルが無駄に大きく、展示 PC の負荷も上がります。

古い PowerPoint の `.wmv` はブラウザで再生できないので変換が必要です。

```sh
ffmpeg -i 発表.wmv -c:v libx264 -preset slow -crf 22 -pix_fmt yuv420p \
  -c:a aac -b:a 128k -movflags +faststart src/videos/ai-01.mp4
```

### ブラウザが求める形式

| 項目 | 必要な形式 | よくある NG |
|---|---|---|
| コンテナ | MP4 | .mov / .avi / .wmv / .mkv |
| 映像 | H.264（AVC） | HEVC（H.265）、ProRes |
| 音声 | AAC | PCM、AC-3 |
| ピクセル形式 | yuv420p | yuv422p / yuv444p |

`-pix_fmt yuv420p` は必須です。これが無いと一部の動画が Chrome で真っ黒になります。

### 変換が要るかの確認

動画ファイルを Chrome にドラッグ＆ドロップして、再生とシークができれば変換不要です。

### ファイル名

`src/videos/<カテゴリid>-<連番>.mp4` にしておくと `src/js/data.js` の `file` と対応が取りやすくなります。

## 展示（無人ディスプレイ）での運用

### 安全装置

**12 秒間再生が進まなければ自動で次の動画へ送ります。** 1 本読み込めなかっただけで
画面が止まるのを防ぐためです。`<video>` のエラー時も同様です。
ドライブ埋め込みは終了を検知できないため 20 秒で送ります。

### 自動再生の条件

- ブラウザは**音ありの自動再生をブロック**します。ページを開いた直後は必ずミュートで始まります
- ナレーションの無い PowerPoint 動画は音声トラック自体が無いので、この制約に掛かりません
- ドライブ埋め込みのままでは自動再生できません（`file` を用意してください）

### 無人でも音を流したい場合

**展示を始めるときに画面へ 1 回だけ触れてください。** クリック・タップ・キー操作の
どれか 1 回で解除され、そのあとはページを開き直すまで**ミュートに戻りません**。
これはこのサイト固有の仕組みではなく、ブラウザ側の仕様（一度でも操作があった
タブでは、以降の音つき自動再生を許可する）を利用しています。

- 音の設定パネル（`音: あり / ミュート`）を直接押しても解除されます
- 何にも触れないまま展示を始めた場合は、最初の動画はミュートで再生され、
  以後もミュートのままになります（＝1 回も触れなければ音は出ません）

**展示 PC の電源が入ると同時に、誰も触らずに音を出したい**場合は、ブラウザ側の
自動再生ポリシー自体を無効にする必要があります。展示専用機であれば、
その PC 専用のショートカットから Chrome を次のオプション付きで起動してください
（通常使っている Chrome のプロファイルとは分けることを推奨します）。

```sh
# macOS の例。展示専用の空プロファイルで起動する
open -na "Google Chrome" --args \
  --autoplay-policy=no-user-gesture-required \
  --user-data-dir="$HOME/hidd-kiosk-profile" \
  "http://localhost:8000/demo/stars.html"
```

このフラグはそのブラウザ起動全体に効くので、展示用と普段使いの Chrome を
分けておくと安全です（`--user-data-dir` で別プロファイルにする）。

### 注意点

- タブが見えていないあいだは球体の回転も自動再生も止まります（無駄な描画をしないため）。
  展示機ではブラウザを前面に出したままにしてください
- OS の「視差効果を減らす」設定が有効だと自動回転しません
