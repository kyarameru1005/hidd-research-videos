# 動画データの入れ方

**カテゴリのフォルダに動画ファイルを置くだけです。** ファイルを編集する必要はありません。

## 動画を追加・差し替える

動画ファイルを、カテゴリごとのフォルダに入れます。

```
src/videos/
  ai/          AI・機械学習・知能システム
  game/        ゲーム・VR・デジタルコンテンツ
  web/         Webサービス・アプリケーション開発
  security/    サイバーセキュリティ・ネットワーク
  iot/         IoT・ロボティクス・組込みシステム
```

置いた動画 1 本につき球体の星が 1 つ増え、そのカテゴリの明るい星（1 等星）の
まわりに自動で散らばります。星を押せばその動画が再生されます。
**`python3 serve.py` で開いていれば、ブラウザを再読み込みするだけで反映されます**
（サーバーの再起動も要りません）。

### ファイル名がそのまま表示になる

```
多層防御の構築とKali Linuxを活用した検証に関する実践研究（磯部泰良）.mp4
└──────────────── タイトル ────────────────┘└─ 発表者 ─┘
```

| ファイル名 | タイトル | 発表者 |
|---|---|---|
| `研究テーマ（山田）.mp4` | 研究テーマ | 山田 |
| `研究テーマ(山田　田中).mp4` | 研究テーマ | 山田 田中 |
| `研究テーマ_山田.mp4` | 研究テーマ | 山田 |
| `研究テーマ.mp4` | 研究テーマ | （なし） |
| `01_研究テーマ（山田）.mp4` | 研究テーマ | 山田 |

- 括弧は**半角 `()` でも全角 `（）` でも**、開きと閉じが食い違っていても拾います
- `【２期】` のような角括弧は**タイトルの一部として残ります**
- ダウンロード時に付く末尾の ` (1)` は捨てます
- 先頭の `01_` は並び順を決めるための番号で、表示には出ません

**そのままの名前で置いて構いません。** 配布された動画のファイル名は
たいていこの形になっているので、リネームは不要です。

### 並び順

ファイル名順です。順番を指定したいときは、**そのフォルダの全ファイルに**
`01_` `02_` … と番号を付けてください（一部だけ付けると番号付きが先に固まります）。

### 動画を消したいとき

フォルダからファイルを消して再読み込みするだけです。星も一緒に消えます。

### フォルダが空のとき

そのカテゴリだけ `src/js/data.js` に書かれた確認用の記述（`videos/sample/` の
色パターン）が使われます。実物を入れる前でもページは壊れません。

### Git には入りません

動画の実物は **Git に入れません**（`.gitignore` 済み）。GitHub は 1 ファイル 100MB が
上限のためで、USB や共有ドライブで配布し、展示機のフォルダに置いてください。
`src/videos/sample/` だけは動作確認用に Git に含めています。
動画ファイルの形式（変換が必要か等）は [operations.md](operations.md) を参照してください。

### 仕組み

`serve.py` がフォルダを走査して `src/js/videos.js` を書き出し、`src/js/data.js` が
それを読んで各カテゴリの動画一覧を組み立てます。
`src/js/videos.js` は**生成物なので手で編集しないでください**（上書きされます）。
`git status` に差分として出ますが、コミットする必要はありません。

## カテゴリを増減する

同じく `src/js/data.js` の `categories` を編集します。

| キー | 用途 |
|---|---|
| `id` | URL に使う識別子（`category.html?cat=<id>`） |
| `label` | カテゴリ名。球体・一覧・見出しすべてで使う |
| `accent` | そのカテゴリのアクセントカラー |
| `description` | カテゴリページの説明文 |

**球体上の配置は自動です。** 配列に足す／減らすだけで並び直ります（記載順＝並び順）。
5 個までは「上・右・下・左・後ろ」の軸方向へ順に割り当て、6 個以上になった場合は
正面を空けたまま真上から等間隔のリングへ自動で切り替わります。
正面は HIDD の表示用に常に空きます。配置の指定項目はありません。

|---|---|---|---|
| 1 | AI・機械学習・知能システム | 上 | 青 `#5ac8fa` |
| 2 | ゲーム・VR・デジタルコンテンツ | 右 | 桃 `#ff7ac6` |
| 3 | Webサービス・アプリケーション開発 | 下 | 緑 `#7affa8` |
| 4 | サイバーセキュリティ・ネットワーク | 左 | 橙 `#ffc861` |
| 5 | IoT・ロボティクス・組込みシステム | **後ろ** | 紫 `#b58cff` |

5 番目は球体の裏側にあるため既定の向きでは見えません。球体を回すと正面に出てきます
（画面下部の一覧からはいつでも選べます）。並び順を変えたい場合は配列の順番を入れ替えてください。

**カテゴリを増やしたら、`src/videos/` に同じ名前（`id`）のフォルダを作ってください。**
そこに置いた動画がそのカテゴリの星になります。
