# 動画データの入れ方

編集するのは **`src/js/data.js` の 1 ファイルだけ**です。

## 動画を追加・差し替える

各カテゴリの `videos` 配列を書き換えます。

```js
{
  title: 'AR を用いた展示ガイドの制作',   // 動画のタイトル
  presenter: '〇〇研究室',                // 発表者・研究室名（省略可）
  summary: '一行程度の概要。',            // 概要（省略可）
  driveId: '1AbCdEfGhIjKlMnOpQrStUvWxYz', // Google ドライブのファイル ID
  file: 'videos/ai-01.mp4',               // ローカルの動画（任意）
}
```

### `driveId` の調べ方

ドライブで動画を右クリック →「リンクをコピー」で得られる URL の、`/d/` と `/view` に挟まれた部分です。

```
https://drive.google.com/file/d/1AbCdEfGhIjKlMnOpQrStUvWxYz/view?usp=sharing
                                ^^^^^^^^^^^^^^^^^^^^^^^^^^^^ ここが driveId
```

ドライブ側の共有設定を **「リンクを知っている全員 / 閲覧者」** にしてください。
限定公開のままだとサイト内の埋め込みプレーヤーで再生できません。

### `file` を書くと何が変わるか

| 指定 | 再生方式 | 自動再生 | 終了検知 | 再生位置の復元 |
|---|---|---|---|---|
| `file` あり | `<video>` | ○ | ○ | ○ |
| `driveId` のみ | ドライブの iframe | × | × | × |

ドライブの埋め込みは**別オリジンの iframe なので JavaScript から操作できません**。
放置時の自動再生（展示モード）を使うには `file` が必要です。
`file` は書いたものから順に対象になるので、全部揃うまで待つ必要はありません。

動画ファイルは `src/videos/` に置きます。**実物は Git に入れません**（`.gitignore` 済み）。
GitHub は 1 ファイル 100MB が上限のためで、USB や共有ドライブで配布し、展示機の `src/videos/` に置いてください。
`src/videos/sample/` だけは動作確認用に Git に含めています。

## カテゴリを増減する

同じく `src/js/data.js` の `categories` を編集します。

| キー | 用途 |
|---|---|
| `id` | URL に使う識別子（`category.html?cat=<id>`） |
| `label` | カテゴリ名。球体・一覧・見出しすべてで使う |
| `accent` | そのカテゴリのアクセントカラー |
| `description` | カテゴリページの説明文 |

**球体上の配置は自動です。** 配列に足す／減らすだけで並び直ります（記載順＝並び順）。
5 個までは「上・右・下・左・後ろ」の軸方向へ順に割り当て、6 個以上になった場合は
正面を空けたまま真上から等間隔のリングへ自動で切り替わります。
正面は HIDD の表示用に常に空きます。配置の指定項目はありません。
