# 先行研究の紹介動画の統合サイトの作成

## 内容

- 動画のカテゴリは４つに分けられる
- 真ん中に球体を配置してその球体を回せるようにしてカテゴリ選択ができるようにしてほしい
- サイトに入ったら何かのアニメーションを入れて真ん中に球体をおく
- デフォルトの向きにHIDDと書いて欲しい
- 左右上下は以下のカテゴリにして欲しい
    - AI・データサイエンス／AI・機械学習・知能システム
    - ゲーム・XR・デジタルコンテンツ／ゲーム・VR・エンターテインメント開発
    - Web・アプリ・DXシステム開発／Webサービス・業務システム・DX開発
    - IoT・セキュリティ・ロボティクス／IoT・ネットワーク・セキュリティ・ロボット
- カテゴリをクリックしたら動画のリンクのあるページにいくようにしたい
- URLを配置してそれをクリックしたらGoogleドライブにある動画が表示される

## 制約
- ブラウザで表示できること
- そこまでスペックの良いPCで動かすわけではありません
